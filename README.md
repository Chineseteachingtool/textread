# 課文消失跟讀

學生跟讀用的課堂小遊戲：課文會一個字一個字亮起、變色、消失，學生要在文字消失前跟著念完。

## 功能

- 速度：慢／中／快／非常快（每分鐘 60／80／100／120 字），標點不計入字數
- 開始前 5→1 倒數動畫，可暫停、繼續、重來（空白鍵開始／暫停，R 重來）
- 拼音開關（自動標注，多音字可在字後加 `[拼音]` 修正，例如 `銀行[háng]`）
- 對話標色：自動辨識「」中的說話角色並配色，可用 `{角色}「……」` 指定；支援「老師：大家好」劇本格式
- 老師可上傳或拖放 .txt 課文（UTF-8／Big5），或直接貼上文字
- 字級調整、全螢幕（可捲動）

## 使用

直接用瀏覽器開啟 `index.html` 即可，拼音功能已內嵌，離線也能使用（楷書字型需網路，否則改用系統字體）。

開啟 GitHub Pages（Settings → Pages → Deploy from branch → `main` / root）即可產生網址分享給學生。

內嵌套件：[pinyin-pro](https://github.com/zh-lx/pinyin-pro)、[opencc-js](https://github.com/nk2028/opencc-js)（皆為 MIT 授權）。
